# codingpirates
Teaching materials

## GitHub vibecoding

An interactive, six-mission guide to building your first web app with
[the TypeScript static template](https://github.com/jbj/typescript-static-template).
Includes checkboxes saved in browser local storage, completion confetti, and
optional verification and maintainer guidance. No dependencies or build step.

### Publish on GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, select **main** and
**/ (root)**, then save. The guide will be available at
<https://jbj.github.io/codingpirates/github-vibecoding/>.
It lives in `github-vibecoding/`, leaving room for other teaching pages.

### Preview locally

From the repository root, run `python -m http.server 8000` and open
<http://localhost:8000/github-vibecoding/>. Check off missions and reload to
confirm saved progress. Uncheck any mission to revisit it. Progress is local
to the browser and origin; private browsing or blocked storage may not retain it.
Celebrations respect the browser’s reduced-motion preference.
